# Limitations

The published study identifies several limitations that should be considered when interpreting the results.

## 1. Dataset Size

The benchmark contains 47 curated patient records. The relatively small dataset limits the generalizability of the empirical findings.

## 2. Simulation of Classical Reasoning

Propositional Logic and First-Order Predicate Logic implementations were simulated using Python conditionals and SQL queries rather than dedicated logic engines.

## 3. Manual Knowledge Curation

Subclass relationships in the ontology and Knowledge Graph were manually curated. This introduces the possibility of representational bias.

## 4. Scope of Evaluation

The study focuses on a controlled cardiovascular Question Answering setting and therefore does not establish performance across all clinical domains or larger real-world healthcare environments.

## Future Evaluation

The paper identifies larger-scale clinical datasets, automated ontology alignment, automated Knowledge Graph construction and hybrid neuro-symbolic approaches as potential directions for further research.
